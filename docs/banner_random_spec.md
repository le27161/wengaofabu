# 轮播图随机选取功能规格

## 目标

门户设置页的「首页轮播图」配置中，新增“随机选 5 篇”能力：管理员不再需要逐条翻阅选择，一键从**所有带封面且已发布**的文稿中随机选取 5 篇加入轮播列表，仍可继续手动调整与保存。

## 交互设计

- 「从文稿中选取」按钮旁新增「随机选 5 篇」按钮（带随机图标，点击时 loading）。
- 点击后调用随机接口，将结果与当前轮播列表按 `article_id` 去重后追加：
  - 若当前轮播为空，直接填入 5 篇；
  - 若已有配置，只追加不重复项，并提示“新增 X 张、跳过已存在 Y 张”；
  - 若无任何带封面已发布文稿，提示暂无可用文稿。
- 随机结果只写入列表，不自动保存，沿用现有“保存轮播配置”按钮统一提交，避免误覆盖。

## 数据契约

新增接口（管理员）：

`GET /api/portal/banner/random?count=5`

参数：

| 参数 | 说明 |
| --- | --- |
| count | 随机数量，默认 5，范围 1~10 |

返回：

```json
{
  "items": [
    {
      "id": 12,
      "title": "标题",
      "cover_url": "https://.../cover.jpg",
      "categories": [{ "id": 3, "name": "栏目名" }],
      "link": "/article/12"
    }
  ]
}
```

业务规则：

- 候选范围：`status == 'published'` 且 `cover_url` 非空（与轮播“仅带封面可选”一致）。
- 随机选取：后端 `random.sample`；不足 count 时返回全部可用文稿。
- 权限：仅系统管理员（`require_roles("admin")`），与现有门户模块配置接口一致。
- 无分页：候选为有限集合，一次返回。

## 前端改动

1. `frontend/src/api/index.js`：`portalApi` 增加 `bannerRandom(count)`。
2. `frontend/src/views/admin/PortalManageView.vue`：
   - 轮播面板操作区新增「随机选 5 篇」按钮；
   - 新增 `randomizeBanner()`：请求接口 → 与 `bannerSlides` 按 `article_id` 去重追加 → 消息提示；
   - 面板提示文案补充“可随机选取”。

## 成功标准

- 点击「随机选 5 篇」后轮播列表出现随机带封面已发布文稿（数量 ≤ 5，去重）。
- 接口无候选时给出友好提示；非管理员调用返回 403。
- 原有手动选取、移除、保存流程不受影响。
- 后端冒烟测试新增对应断言并可通过。
