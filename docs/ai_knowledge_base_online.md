# AI 知识库在线化规格

> 状态：已确认（2026-08-14）

## 1. 目标

将 AI 协作台"AI 智能分类"使用的本地知识库文件（`backend/app/aimodel/knowledge_base.json`）
迁移为后台「系统设置」中的在线配置项，管理员可在页面上直接编辑 JSON 并保存，**保存后立即生效**，
无需重启后端、无需修改本地文件。

## 2. 数据结构

复用现有 `system_settings` 表，新增配置键：

| 配置键 | value_type | 说明 |
| --- | --- | --- |
| `ai_knowledge_base` | `json` | AI 知识库（人物/关键词 → 分类强兜底）。值为 JSON 对象：`{"关键词": {"title": "描述", "category": "分类名"}}` |

- 默认值：把当前 `knowledge_base.json` 内容（斯塔默/米莱/元勋 → 政治，泰勒·斯威夫特 → 娱乐）写入种子数据
- 前端：系统设置页「其他配置」按 `json` 类型自动渲染文本域 + 保存按钮（已有机制，无需改前端）

## 3. 读取优先级（predict.py）

`predict_fun` 内加载知识库时：

1. **数据库优先**：读 `system_settings.ai_knowledge_base`，解析为 dict；每次调用实时读取（调用频率低，保证在线修改立即生效）
2. **本地文件兜底**：数据库无配置或解析失败时，回退读 `backend/app/aimodel/knowledge_base.json`（兼容老环境/未初始化场景）
3. 两者都失败：按空知识库处理，走模型预测

## 4. 接口

- 新增配置键读写复用现有 `/api/settings`（GET 列表 / PUT `{config_key}` 更新），不新增接口
- 权限：仅管理员（与现有系统设置一致）

## 5. 前端交互

- 系统设置页「其他配置」自动出现 `AI 知识库` 配置项（textarea 编辑 JSON + 保存按钮 + JSON 语法校验），无需额外开发
- 保存成功后下一次 AI 分类调用立即使用新知识库

## 6. 成功标准

1. 后台系统设置可看到并在线修改 `ai_knowledge_base`
2. 修改后调用 AI 分类：命中新写入的关键词返回配置的分类（无需重启）
3. 未配置/配置损坏时仍可回退本地文件，分类不中断
4. `smoke_test.py` 增加：设置在线知识库 → 分类命中断言 → 恢复原配置
5. 兼容：现有本地 `knowledge_base.json` 保留不删除（作为兜底与迁移来源）

## 7. 不做的事

- 不新增知识库管理页面（系统设置已有通用 json 编辑能力，够用）
- 不做高频缓存（每次调用读库，当前调用频率低；后续量大再引入内存缓存 + 版本号）
